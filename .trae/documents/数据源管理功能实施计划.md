# 数据源管理功能实施计划

## Context

tools.html 用户每次上传 Excel 都会生成档案和记录册，但数据没有持久化。用户希望上传时自动将数据保存到 Cloudflare（通过 D1 + R2），并提供一个公开的管理页面查看/下载/删除已上传的数据源。

## 方案概述

- **R2**：存储原始 Excel 文件 + 解析后的完整 JSON 数据
- **D1**：仅存储元数据（文件名、记录数、上传时间等）
- **管理页面**：新建 `datasource/admin.html`，无需密码，完全公开访问

---

## 1. D1 表结构

```sql
CREATE TABLE IF NOT EXISTS data_sources (
    id          TEXT PRIMARY KEY,   -- UUID，如 ds_abc123
    file_name   TEXT NOT NULL,      -- 原始文件名
    file_size   INTEGER NOT NULL,   -- 文件大小（字节）
    record_count INTEGER NOT NULL,   -- 记录行数
    field_names TEXT NOT NULL,      -- JSON 数组，如 ["姓名","部门","相片"]
    r2_key      TEXT NOT NULL,      -- R2 中 JSON 文件的 key
    r2_excel_key TEXT NOT NULL,     -- R2 中原始 Excel 的 key
    created_at  TEXT NOT NULL       -- ISO8601 时间
);
```

## 2. API 设计（functions/api/datasource.js）

### POST /api/datasource（上传，公开）
FormData: `file`(Excel), `meta`(JSON字符串 `{recordCount, fieldNames}`)

流程：
1. 读取 FormData 中的 Excel 文件
2. 用 XLSX 解析为 JSON 字符串
3. 生成 UUID 作为 id
4. 将原始 Excel 和 JSON 数据分别 PUT 到 R2（两个 key）
5. 向 D1 插入元数据记录
6. 返回 { success: true, id, fileName, recordCount, createdAt }

### GET /api/datasource（列表，公开）
Query: `page`(默认1), `pageSize`(默认20)

返回：{ list: [...], pagination: { page, pageSize, total, totalPages } }

### GET /api/datasource?id=xxx（下载JSON，公开）
返回 R2 中对应的 JSON 文件内容（Content-Type: application/json）

### GET /api/datasource/excel?id=xxx（下载原始Excel，公开）
返回 R2 中对应的原始 Excel 文件（Content-Type: application/vnd.openxmlformats-...）

### DELETE /api/datasource?id=xxx（删除，公开）
从 R2 删除两个文件，从 D1 删除元数据记录。

## 3. 前端改造（tools.html）

修改 `onSharedExcelChange()`，在解析 Excel 成功后**静默**调用 `POST /api/datasource` 上传到云端：

```javascript
// onSharedExcelChange 末尾添加：
// 静默上传数据源到云端（失败不影响本地功能）
uploadDataSourceToCloud(file, json).catch(() => {});
```

上传函数 `uploadDataSourceToCloud(file, jsonData)`：
- 构造 FormData，调用 `POST /api/datasource`
- 成功后记录返回的 id（sharedDataSourceId）
- 失败则静默忽略，不弹窗不阻止主流程

## 4. 管理页面（datasource/admin.html，新建）

**无需密码，公开访问**

功能：
- 顶部 Banner：返回首页链接 + "数据源管理后台"标题
- 数据源卡片列表（分页，每页20条）
  - 每个卡片显示：文件名、记录数、上传时间
  - 操作按钮：[查看明细] [下载Excel] [删除]
- 点击"查看明细"：弹窗显示 JSON 数据（支持滚动）
- 删除需 confirm 确认

页面引用 `lib/base.css` 和 `lib/base.js`，风格与项目现有页面保持一致。

## 5. wrangler.toml 配置

```toml
name = "tz-app"
compatibility_date = "2024-01-01"

[[d1_databases]]
binding = "DB"
database_name = "tz-datasource"
database_id = "<创建后填入>"

[[r2_buckets]]
binding = "DATA_BUCKET"
bucket_name = "tz-datasource-files"
```

---

## 6. 部署步骤

1. **本地初始化 D1**：执行 `datasource.sql` 建表
2. **Cloudflare Dashboard**：手动创建 R2 存储桶 `tz-datasource-files`
3. **填入 database_id**：将 Wrangler 返回的 ID 填入 wrangler.toml
4. **部署**：wrangler deploy
5. **初始化 SQL**：
   ```bash
   wrangler d1 execute tz-datasource --file=./datasource.sql
   ```

## 8. 验证方法

1. 访问 tools.html，上传任意 Excel 文件，检查 Network 中有 POST /api/datasource 请求
2. 访问 datasource/admin.html，应直接显示管理界面（无密码）
3. 点击"查看明细"，应显示解析后的 JSON 数据
4. 点击"下载Excel"，应触发浏览器下载
5. 点击"删除"，刷新后列表应更新
